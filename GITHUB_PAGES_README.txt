Reva Nexus V11 — GitHub Pages package

This version is prepared for GitHub Pages and includes:
- Complete static website assets (HTML/CSS/JS/images).
- New Digital Products page in English, Arabic and French.
- New TechViberaFi YouTube page with the supplied channel link.
- Navigation links to both pages across the public site.
- Existing AI Agents, Influencers, Demos and Advertising pages.

IMPORTANT FOR GITHUB WEB UPLOAD
1. Upload the CONTENTS of this folder to the repository root.
2. Do not upload the ZIP file itself.
3. The three campaign MP4 files are intentionally excluded because GitHub's browser upload limit is 25 MB per file.
4. The site will still load normally without those MP4 files. The influencer/advertising video area should be connected later to Supabase Storage or another video host.
5. GitHub Pages is a static host. The Admin dashboard's /api/* login, database publishing and media upload functions require the Node/Supabase backend; they do not run on GitHub Pages alone.
6. Keep file names and capitalization unchanged.
